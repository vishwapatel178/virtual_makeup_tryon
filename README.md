
# Virtual Makeup Try-On

A desktop application that enables users to virtually try on makeup using Computer Graphics and Image Processing techniques.

## Features
- Upload a facial image
- Face detection using MediaPipe
- Virtual lipstick, blush, and eyeshadow
- Adjustable makeup intensity
- Before/After comparison
- Save edited image

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
- Tkinter
